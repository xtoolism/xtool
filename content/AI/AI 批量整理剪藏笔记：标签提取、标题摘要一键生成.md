## 🤯为什么我们需要**批量自动打标**？

信息爆炸时代，剪藏太容易，整理太难。

**你不是没保存信息，而是信息太乱没法用。**

⛔ 手动整理成本太高（谁有空一篇篇起标题、加标签？）
⛔ 没有元数据的笔记，回顾成本巨大
⛔ 每次回头看旧笔记，只觉得 " 好乱、没用、删掉算了 "

但其实只要提前加上：
- 🏷 标签：这篇文章讲的是哪个主题？
- 📂 分类：它属于哪个知识领域？
- ✍️ 摘要：不点开我也能知道大概讲了啥

你的笔记就会从 " 信息垃圾场 " 变成真正的**结构化知识库**。

## 🛠 我用了哪些插件？（都是免费）

我用的是纯本地 Obsidian 插件组合：

| 插件                      | 作用            |
| ----------------------- | ------------- |
| `obsidian-exmemo-tools` | AI 标题/标签/摘要提取 |
| `obsidian-linter`       | 自动格式统一格式      |
| `quickadd`              | 执行脚本、批量处理     |
|                         |               |

💡重点：所有 AI 处理都是本地进行，可接入自己的 **OpenRouter** API Key，。

OpenRouter 提供了众多开源和商业模型的免费接口，上免费的模型推荐：
1. google/gemini-2.0-flash-exp:free
2. qwen/qwen3-30b-a3b:free
3. deepseek/deepseek-chat-v3-0324:free

实测这几个提取都还行，gemini 速度实测比较快，目前个人在用。

通过 QuickAdd 调用 OpenRouter API，我们可以让 AI 自动分析笔记内容，一键生成与之相关的标签列表、摘要文本和分类建议，并写回到笔记的 Frontmatter 中，从而实现元数据的自动补全。
