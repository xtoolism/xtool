# tmp
`问答式日记` 通过提问触发内省，适合自由写作、自我探索。
我的日记模板分 4 大类，每类 3 个问题
1. 🧐 observe - 观察类（聚焦感官 / 外部世界 / 注意力所在）
2. 😊 good - 积极类（关注正向情绪 / 高光时刻 / 内在能量）
3. 😣 difficult - 困难类（识别挑战 / 阻力 / 情绪波动）
4. ✨ different - 变化类（自我觉察 / 反思 / 优化）

## 问答式日记的设计细节

为了提升日记记录的效率与可靠性，我将原本基于单个 QuickAdd Capture（一次弹出多个变量窗口）的方法，优化为使用一个 **Macro（宏）+ 多个 Capture 组合** 的方式。

原方案中，一个 Capture 模板包含 12 个变量，虽然能一次性填写所有内容，但填写过程中如果中途取消，**整个数据会丢失**，这对于日记记录体验是一个明显痛点。

因此，我将其拆分为 **4 个 Capture 模块**，每个模块只包含 3 个问答项，通过 Macro 按顺序依次触发。这种拆分方式不仅降低了填写时的心理负担，也显著减少了因中途退出导致的数据丢失风险。

在设计上，我保持了**每条记录为一行、主标签 + 子标签并存**的结构（如 `#good #喜悦`），虽然存在一定的标签冗余，但这种方式能更方便后续利用 Dataview 实现**自动化聚合与周/月总结**。

每个 Capture 的变量弹窗标题中都附有**精炼的提示语**，引导我快速聚焦当天的所见、所感、所思与所得，从而降低思索成本，让我能够在 **5 分钟内**以**问答形式**自然完成当日的复盘记录。整套流程支持递进式反思，兼顾工作、生活、健康、学习等维度，既结构清晰，又足够灵活。

为了回顾跟轻松，我添加了 summary 章节用来一句话总结日记：集成了 `Local GPT` 插件，使用 `AI自动总结` 日记内容。
