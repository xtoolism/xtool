# 轻松写出结构化日记：QuickAdd + 问答模板 + AI 总结
日记是一切复盘的起点。用结构化的问答方式，加上 QuickAdd 自动化与 AI 总结能力，让日记变得高效、轻松、可持续。每天 5 分钟，记录所见所感，轻松养成自我反思的好习惯，也为后续的周/月总结打下根基。

## QuickAdd 问答式日记 - 使用演示
![[file-20251002111859205.mp4]]
`问答式日记` 通过提问触发内省，适合自由写作、自我探索。

我的日记模板由**observe / good / difficult / different** 4 大维度构成闭环
1. **🧐 观察 observe**：记录客观发生
2. **😊 积极 good**：捕捉正向能量
3. **😣 困难 difficult** ：识别挑战与反馈
4. **✨ 复盘 different** ：自我觉察与行动改进

### 问答式日记的设计细节

为了提升日记记录的效率与可靠性，我将原本基于单个 QuickAdd Capture（一次弹出多个变量窗口）的方法，优化为使用一个 **Macro（宏）+ 多个 Capture 组合** 的方式。

原方案中，一个 Capture 模板包含 12 个变量，虽然能一次性填写所有内容，但填写过程中如果中途取消，**整个数据会丢失**，这对于日记记录体验是一个明显痛点。

因此，我将其拆分为 **4 个 Capture 模块**，每个模块只包含 3 个问答项，通过 Macro 按顺序依次触发。这种拆分方式不仅降低了填写时的心理负担，也显著减少了因中途退出导致的数据丢失风险。

在设计上，我保持了**每条记录为一行、主标签 + 子标签并存**的结构（如 `#good #喜悦`），虽然存在一定的标签冗余，但这种方式能更方便后续利用 Dataview 实现**自动化聚合与周/月总结**。

每个 Capture 的变量弹窗标题中都附有**精炼的提示语**，引导我快速聚焦当天的所见、所感、所思与所得，从而降低思索成本，让我能够在 **5 分钟内**以**问答形式**自然完成当日的复盘记录。整套流程支持递进式反思，兼顾工作、生活、健康、学习等维度，既结构清晰，又足够灵活。

为了回顾更轻松，我添加了 summary 章节用来一句话总结日记：集成了 `Local GPT` 插件，使用 `AI自动总结` 日记内容。

> 注意：如果日记隐私比较多，可以使用 LmStudio 类的本地大模型服务，或者自己人工总结

### QuickAdd 问答式日记模板

Obsidian 内，使用这个 QuickAdd 模板即可轻松实现问答式日记

```markdown
### 🧐 observe - 观察类（环境 / 他人）
* #observe #环境 {{VALUE:观察-环境：今天哪些细节引起了你的注意？（天气、声音，光影、味道、空间布局）}}
* #observe #环境 {{VALUE:观察-环境：今天哪些细节引起了你的注意？（天气、声音，光影、味道、空间布局）}}
* #observe #他人 {{VALUE:观察-他人：今天谁（家人、孩子、同事、伴侣）做了什么具体的事？他们说了哪句话、有什么面部表情或动作？}}

### 😊 good - 积极类（成就 / 喜悦 / 感恩）
* #good #成就 {{VALUE:积极-成就：今天你做成了什么事？推进了哪个计划？有没有哪怕一点小突破？}}
* #good #喜悦 {{VALUE:积极-喜悦：什么时候你感到开心、轻松或觉得有趣？和谁一起，是哪句话，哪件事，哪种氛围带来的？}}
* #good #感恩 {{VALUE:积极-感恩：今天你收到了哪些支持或善意（回应 / 帮助 / 理解 / 陪伴 / 美景 / 美食 / 体贴）？是否对什么人或事物心怀感激？}}

### 😣 difficult - 困难类（挑战 / 情绪 / 身体）
* #difficult #挑战 {{VALUE:困难-外部挑战：今天你遇到了哪些外部挑战？事情进行到哪被打断或卡住了？}}
* #difficult #情绪 {{VALUE:困难-负面情绪：你在什么时候感受到不适的情绪（自卑 / 焦虑 / 愤怒 / 失落 / 烦躁 / 羞愧 / 恐惧 / 紧张）？那一刻发生了什么？}}
* #difficult #身体 {{VALUE:困难-身体反馈：你的身体有没有发出一些信号（疲惫 / 酸痛 / 困倦 / 紧绷 / 头晕 / 心悸）？是否感到不舒服或异常？你是怎么回应的？}}

### ✨ different - 变化类（觉察 / 改进）
* #different #觉察 {{VALUE:变化-觉察：我今天又出现了什么反应模式？比如有没有哪一刻你心里闪过我怎么又拖延了、又没有用心倾听、又急着回应了别人、又忽略了自己的感受……}}
* #different #改进 {{VALUE:变化-改进：针对今日问题（挑战，情绪，身体）制定明日可行的小步优化（时间分配，情绪管理，沟通方式，寻求外援）}}
```

## 🧐 observe - 观察类（环境/他人）

从外部环境，他人 2 方面记录自己的观察，要保证观察而非评判（`非暴力沟通` 的观察方法）。

### 环境
今天哪些细节引起了你的注意？（天气、声音，光影、味道、空间布局）

### 他人
今天谁（家人，孩子，同事，伴侣）做了什么具体的事？他们说了哪句话、有什么面部表情或动作？

## 😊 good - 积极类（成就/喜悦/感恩）
从成就，喜悦，感恩 3 方面记录今天达成的目标和正向情绪。

### 成就
今天你做成了什么事？推进了哪个计划？有没有哪怕一点小突破？

### 喜悦
什么时候你感到开心、轻松或觉得有趣？和谁一起，是哪句话，哪件事，哪种氛围带来的?

### 感恩
今天你收到了哪些支持或善意（回应/帮助/理解/陪伴/美景/美食/体贴）？是否对什么人或事物心怀感激？

## 😣 difficult - 困难类（挑战/情绪/身体）
从挑战（外部），情绪（心理），身体（生理）3 方面记录今天遇到的困难。

### 挑战
外部挑战：今天你遇到了哪些外部挑战？事情进行到哪被打断或卡住了？

### 情绪
负面情绪：你在什么时候感受到不适的情绪 (自卑/焦虑/愤怒/失落/烦躁/羞愧/恐惧/紧张)？那一刻发生了什么？

### 身体
身体反馈：你的身体有没有发出一些信号（疲惫/酸痛/困倦/紧绷/头晕/心悸）？是否感到不舒服或异常？你是怎么回应的？

## ✨ different - 变化类（觉察/改进）
从改进觉察，改进 2 个方面记录可以做出的改变。

### 觉察
我今天又出现了什么反应模式？比如有没有哪一刻你心里闪过我怎么又拖延了、又没有用心倾听、又急着回应了别人、又忽略了自己的感受……

### 改进
针对今日问题（挑战，情绪，身体）制定明日可行的小步优化（时间分配，情绪管理，沟通方式，寻求外援）

## 结语
**日记是一切复盘的起点**，也是灵感的蓄水池。没有日记，周总结和月总结也就失去了根基。

这套结构化问答模板，结合 `QuickAdd` 的快速填写流程和 `AI 自动总结` 的自动化处理，正是为了让写日记这件事变得更轻松、更持续。

日记从来不是写给别人的故事，而是 `一种与自己对话的方式`。如果你也想重新拾起记录的节奏，不妨就从今天开始试试。
