# 告别图床：Obsidian 这个插件，让公众号发布回归纯粹的本地化

Hello，大家好，我是麦冬。

今天这篇文章，从我在 Obsidian 里写完最后一个字，到你现在看到它，总共用时**不到 1 分钟**。

这背后，没有复杂的操作，没有多个网页间的跳转，更没有对 `图床` 的依赖。我只是用了一个 Obsidian 插件，就实现了从本地写作到公众号发布的一键丝滑体验。

这，正是我今天要分享的核心：**如何让我们的创作，回归纯粹的本地化，并夺回对个人知识库的绝对掌控权。**

## 无法忍受的过去：那个被图床绑架的流程
如果你也是 Obsidian 的同好，一定明白 `本地化` 三个字的神圣之处。我们的笔记、链接、附件，都安安稳稳地躺在自己的硬盘里，这种踏实感无可替代。

但在发布到公众号时，这种踏实感就被打破了。看看我过去的流程：

1. **本地创作：** 在 Obsidian 中完成 Markdown 写作和配图。
2. **图床处理：** 使用 `image-upload-toolkit` 等插件，将本地图片上传到**第三方图床**，再把文章转成图片外链的形式。
3. **在线排版：** 粘贴到 `md.doocs.org` 在线排版网站，进行二次加工。
4. **后台发布：** 最后粘贴到公众号后台，检查发布。

这个流程最大的痛点是什么？是第二步。**我们被迫将本属于知识库一部分的图片，上传到云端。** 这不仅意味着繁琐的操作，更意味着：

- **数据割裂：** 你的知识库不再是完整的 `本地` 库。
- **潜在风险：** 如果图床服务不稳定或停运，你所有文章的图片都会变成一个无法打开的 `X`。
- **效率低下：** 每次都要等待图片上传，消磨耐心。

这个流程，违背了我们建立本地知识库的初衷。是时候和它说再见了。

## 本地化新方案：mp-preview
现在，认识一下我的新伙伴：**`mp-preview`** 插件。
![[file-20251002111841519.png]]
它让我的发布流程进化得如此纯粹：

1. **本地创作：** 在 Obsidian 里写稿、本地配图。
2. **本地预览与复制：** 使用 `mp-preview` **直接在 Obsidian 内**预览公众号效果，**它会自动处理本地图片**。点击 `复制到公众号`。
3. **公众号粘贴发布：** 粘贴到公众号草稿，所有文字、样式、**包括图片**，一步到位。

看明白了吗？**我们彻底绕开了图床！** 本地化的方案就是这么酷！图片被插件通过特定方式编码，可以直接粘贴到公众号编辑器里，自动上传到微信素材库，没有外链。

这不仅仅是步骤从 4 步简化到 3 步，这是质的飞跃。它守护了我们知识库的完整性和独立性。

> 现在 3 步就整好了，是有一点进步。
> 不过还有优化的空间：我们可以将 2-3 合成一步，调用微信公众号的 API 创建草稿，小步快走，后面有空再探索。

## 它如何工作？（及安装指南）

`mp-preview` 的核心功能就是将 Markdown（包括本地图片）直接转换为微信兼容的格式。

- **功能特点：** 一键转换、实时预览、丰富模板、自定义样式、一键复制，以及为长文准备的防打扰 `锁定` 功能。
- **安装方法：** 推荐直接在 Obsidian 的社区插件市场搜索 `MP Preview` 进行安装。如果网络不佳，也可以从 Github 手动下载安装。
    - Github 地址: `https://github.com/Yeban8090/mp-preview/releases`

安装启用后，点击侧边栏的公众号图标，你就能立刻体验到这种前所未有的流畅感。

## 为什么我坚持本地优先

工具的迭代，背后是理念的升级。

这次工作流的优化，让我更加坚信 `本地知识库` 的重要性。我们的思想、笔记和创作素材，是我们最宝贵的数字资产。将它们托管在自己的设备上，意味着：

- **所有权：** 数据 100% 属于你，不受任何平台制约。
- **隐私性：** 无需担心第三方服务的数据泄露风险。
- **永恒性：** 只要你的硬盘还在，你的知识库就永远存在，无需担心服务关停。

`mp-preview` 这款插件之所以让我兴奋，正是因为它尊重并实现了这一理念。它补全了 Obsidian `本地优先` 生态在 `发布` 这个环节的最后一块短板。

# 总结：回归创作，掌控所有

从依赖图床的繁琐四步，到如今无需图床、一分钟发布的极简流程，`mp-preview` 带来的不仅是效率的提升，更是一种 `数据归我所有` 的从容和安心。

它让我们的精力可以彻底回归内容创作本身，而不是在工具间的切换和重复劳动中被消耗殆尽。

如果你也想拥有一个完整、独立、强大的本地知识库，并从中高效地向外输出，那么，请务必试试这个方案。
