# 公众号封面设计：开源工具测评
做公众号封面图太费时间？我测试了 4 款开源封面设计工具，包括支持 Unsplash 素材、封面比例配置、文字自动布局，轻量部署也超方便，几分钟生成高质量主图，效率翻倍！

## 我的需求
制作视频号/公众号的背景图，支持配置布局，文字，背景，有大量模板，1 分钟搞定封面图片设计。

| 名称        | 比例       | 尺寸            |
| --------- | -------- | ------------- |
| 公众号首图     | `2.35:1` | `900 * 383`   |
| 视频号封面（横版） | `16:9`   | `1080 * 608`  |
| 视频号封面（竖版） | `6:7`    | `1080 * 1260` |

示例文本


在线素材服务 -**unsplash**
* 我的应用列表： https://unsplash.com/oauth/applications
* 新增应用： https://unsplash.com/oauth/applications/new ，新增后保存 `Access Key`，后面介绍的开源工具，自己部署时用到。
* 演示应用每小时限制 **50 次请求** 。 
* 生产中的应用程序每小时可访问 **5,000 次请求** ，应用程序遵循 [Unsplash 的 API 指南](https://help.unsplash.com/api-guidelines/unsplash-api-guidelines) 和 [条款](https://unsplash.com/api-terms) ,且需要 unsplash 团队的审核。

## 工具测试
### CoverPaint
* 项目地址: https://github.com/youngle316/cover-paint
* 演示地址： https://coverpaint.yanglele.cc/
* 特性：支持本地背景图，也支持按关键词从 Unsplash 搜索在线素材（每个 apiKey 每天 50 次免费搜），配置标题/摘要/作者，有无限的免费在线素材，但只有 1 个模板

![[插图设计工具-20250415091551.jpg]]

### CoverView
* 项目地址: https://github.com/rutikwankhade/CoverView
* 演示地址: https://coverview.vercel.app/editor

![[插图设计工具-20250415135807.jpg]]

### Polotno-Studio
* 项目地址： https://github.com/polotno-project/polotno-studio
* 演示地址： https://studio.polotno.com
* 特性：支持在线的图片/视频/文字/形状素材，提供各类模板，具备图片编辑功能，视频编辑能力
* 缺点：不够开箱即用，中文支持不好，需要自己传中文字体
![[插图设计工具-20250415220531.jpg]]

### PicProse
* 项目地址： https://github.com/jaaronkot/picprose
* 演示地址： https://picprose.pixpark.net/zh
* 特点：
	1. 按社交媒体（如公众号）配置图片尺寸，按设备配置尺寸
	2. 从 unsplash 获取图片素材作为背景
	3. 配置背景，标题/摘要/作者
	4. 有无限的免费在线背景素材：支持按关键词从 Unsplash 搜索在线素材（每个 apiKey 每小时 50 次免费搜）

![[插图设计工具-20250415092302.jpg]]
docker 部署 PicProse

```bash
docker run -d \
--network host \
--name picprose \
--restart always \
-e UNSPLASH_API_KEY=your_api_key \
hausen1012/picprose
```

本地访问地址：
http://localhost:3000
