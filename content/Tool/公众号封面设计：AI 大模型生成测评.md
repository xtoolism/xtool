# 公众号封面设计：AI 大模型生成测评
本文实测文心一言、豆包等 6 大主流 AI 工具生成公众号/视频号封面的能力，发现多数模型存在文字错乱、配色失控问题，仅 文心一言/ChatGPT 精准实现设计要求。未来趋势或走向「AI 生成背景 + 工具排版」的工程化路线，或依赖多模态模型突破。

## 我的需求
我需要制作视频号/公众号的背景图，支持配置布局，文字，背景，模板，所见及所得，工具免费，输入标题能在 1 分钟能输出图片；

| 名称        | 比例       | 尺寸            |
| --------- | -------- | ------------- |
| 公众号首图     | `2.35:1` | `900 * 383`   |
| 视频号封面（横版） | `16:9`   | `1080 * 608`  |
| 视频号封面（竖版） | `6:7`    | `1080 * 1260` |

## 提示词
kimi- 提示词专家智能体:
https://kimi.moonshot.cn/kimiplus/conpg00t7lagbbsfqkq0
基于这个提示词，去评测不同大模型的生成效果

```markdown
主标题：QuickAdd的5分钟问答日记实践
主标题字体：使用一个等宽中文字体，黑色
主题相关内容：我的问答日记模板分 4 大类：🧐 observe，😊 good，😣 difficult，✨ different
配色：采用黄（`#FFDC62`）、绿（`#8EE39A`）、蓝（`#7ACBF7`）三色，呼应微信的配色风格
背景：半透明的彩色几何元素增加视觉层次感，提供层次感但不喧宾夺主
尺寸：1080 * 608
```

# 结语
大模型适合纯背景图片，但涉及到文字就会有幻觉，生成的都是鬼画符，目前 chatgpt 表现好一点，其他的都不太行。
未来的 2 个趋势
1. 大模型生成背景图片，然后调用一个设计工具的 MCP 进行布局排版，字体渲染，用工程化方式解决问题；
2. 训练多模态的大模型，一站式解决问题

我已经放弃大模型一站式生成了，本文的 cover 就是使用开源工具 1 分钟内生成的，下期再分享。
