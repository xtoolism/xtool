# 致所有内容创作者：是时候升级你的发布工具了
你好，我是麦冬，欢迎来到我的 `极客工具`。

不知道你是否和我一样，每次写完文章，都感觉只完成了 90% 的工作。剩下的 10%，也就是发布前的那些琐事——**设置标题、作者、摘要、手动上传封面图、调整格式**——虽然每次只花几分钟，但日积月累，成了一种无形的消耗。

对于我这种对 `重复性劳动` 极度敏感的人来说，这简直无法忍受。于是，我踏上了探索之旅，目标只有一个：**在 Obsidian 里，实现一键自动化发布到微信公众号**。

今天，我将为你分享我的探索成果。我实际测试了市面上主流的 4 款 Obsidian 插件，希望能帮你找到最优解。

## 四款插件，我的自动化探索之旅

为了找到完美的解决方案，我将市面上能找到的插件都深度试用了一遍，以下是我的心路历程。

如何将本地笔记发布文章到微信公众号？在 obsidian 插件中发现有 4 款插件
1. MP Preview
2. WeWrite
3. Wechat Public Platform
4. NoteToMP

每个我都实际测试了，下面逐个给大家分析分析，文末给出我自己当前的选择和对于自媒体工具未来形态的思考。

## MP Preview：漂亮的起点，但不是终点

![[file-20251002111912253.png]]

`MP Preview` 我上期分享过：[告别图床！Obsidian 这个插件，让公众号发布回归纯粹的本地化](https://mp.weixin.qq.com/s/_DAtUArmxxp2P7qEmTo6qA)

它的优点非常突出：主题样式丰富美观，预览体验如丝般顺滑，对普通用户极其友好。

但它的问题也很明显：**它只解决了"看"的问题，没有解决"发"的问题**。你依然需要手动复制，然后到公众号后台一项项地设置。它就像一位出色的设计师，为你做好了精美的样稿，却把最后递交的关键一步留给了你自己。这"最后半公里"的缺失，正是我继续探索的动力。

## Wechat Public Platform：功能强大，但过于"硬核"
![[file-20251002111912418.png]]

这个插件的功能 4 个里面最强的（但是产品化程度不高，不够丝滑），支持公众号的发布草稿，正式发布，还支持百家号，Youtube 的视频发布。

但它的缺点也同样致命。首先，**它没有预览功能**。这意味着你对样式的调整，就像在 `盲人摸象`，必须发布到后台才能看到最终效果，调试成本非常高。
其次，我的主图都是本地的，期望使用当前文章的第一章图片作为主图，但是插件得自己配置图片的路径，很是繁琐。

### Wechat Public Platform：功能列表
![[file-20251002111912577.png]]
- [upload material to WeChatPublic]【微信公众号上传素材】将资源图片、视频上传至微信公众号资源管理（等待黑曜石支持 formdata 体）
- [add draft to WeChatPublic]【微信公众平台添加草稿】微信公众平台草稿箱添加图文资源
- [Release article to WeChatPublic]【微信公众号发布文章】发布图文消息及各类资源并发布到微信公众平台
- [Send all fans to WeChatPublic]【微信公众号发送所有费用】给粉丝群发消息（注：**需要认证有群发权限**）
- [download youtube video] 下载 YouTube 上的视频
- [publish article to baidu bjh news] 将 Obsidian 文章发布到百度的百家号中

### Wechat Public Platform：实现原理
该插件将基于 `frontmatter` 来配置公众号的标题，作者，主图，摘要

```yaml
author: Blake   // for article author
thumb_media_id: "awM_2hMypzpKEBfvr0B09MPmBahsXrBzBhNAzIPXHzRYGjzErk7ZBs4L8nL7VpEY" // media id in wechat platform
banner: "https://images.unsplash.com/photo-1620266757065-5814239881fd?ixlib=rb-4.0.3&q=85&fm=jpg&crop=entropy&cs=srgb&w=2400"
banner_path: "twitter.jpg"  // image file path
open_comment: 0
source_url: ""  // ref article url source
digest: "摘要"
```

## NoteToMP：付费墙前的止步

这款插件我在 2024 年就发现了。但每年 99 元的订阅费，让坚持 `开源优先` 原则的我望而却步。我相信好的工具值得付费，但在此之前，我更想看看免费的生态里有没有足够好的解决方案。

## 终点站 WeWrite：我当前的最优解
![[file-20251002111912773.png]]
经过一番兜兜转转，我最终选择了 `WeWrite`。它完美地平衡了功能、体验和自动化程度，**真正打通了从 Obsidian 到公众号的"最后一公里"**。

`WeWrite` 最打动我的地方，在于它深刻理解了创作者的工作流：

- **沉浸式主题定制**：你可以在 Obsidian 里直接修改 CSS 来定制主题，并且**预览区实时刷新**。这种所见即所得的体验，让你完全不必离开 Obsidian，这太酷了。
- **封面图拖拽设置**：这是一个让我惊呼的功能！可以直接从文章里把图片拖拽到封面图设置区。**这个小小的交互，解决了创作者一个巨大的痛点**。
- **闭环草稿管理**：发布到草稿箱后，你竟然可以在 Obsidian 内直接查看公众号的草稿列表，点击就能使用 webview 预览文章在公众号中的最终效果。这意味着，整个发布流程——从写作、修改、预览到上传——都可以在一个软件内完成。**这正是我想要的"沉浸式"创作体验**。

当然，它内置的主题样式我个人觉得不如 `MP Preview` 那么精致，但这完全可以通过自定义 CSS 来解决。至于它集成的 AI 生成摘要和封面功能，我暂时还没跑通，但手动操作也无伤大雅。

总的来说，`WeWrite` 让我拥有了一个几乎全功能的 `本地公众号后台`。

这篇文章我就是用 WeWrite 发布的，配置好点击发布，成功后自动跳转微信预览页，这丝滑的操作，终于感觉舒坦了。

### WeWrite: 功能列表

- **Excalidraw**：支持直接嵌入 Excalidraw 插件的图表。
- **Mermaid**：支持 Mermaid 图表。
- **LaTeX**：支持 LaTeX 公式。
- **Callout & Admonition**：支持 Obsidian 原生的 Callout 和 Admonition。

- **同义词建议**：为选中的词语提供同义词替换建议。

## 技术原理小科普

实现这一切并不神秘。微信公众号官方提供了免费的 API 接口。开发者只需要让用户配置好自己的 IP 白名单、公众号的 `appKey` 和 `appSecret`，就可以通过代码调用接口，实现上传素材、创建草稿等操作。

技术门槛不高，但它解决的需求却非常刚性，能极大地提升效率。
如果开发者想做这方面的工具，商业模式可以参考 `壹伴` 去提供更多的写作赋能。

> PS 感谢 Obsidian 自由开源生态，让开发者能方便的共享自己的能力。

## 总结：不止于发布，更在于创作

对于 `发布` 这件事，`WeWrite` 已经是我目前能找到的、最接近完美的解决方案。它让我告别了浏览器后台，真正实现了在 Obsidian 内的自动化闭环。

然而，一个真正的 `自媒体创作神器`，不应止步于发布。我心中理想的工具，还应该能 `辅助创作` 本身：

1. **智能选题**：能自动聚合我关注领域的热榜和头条，为我提供源源不断的写作灵感。
2. **AI 标题润色**：酒香也怕巷子深，如果能基于内容一键生成多个爆款风格的候选标题就完美了。
3. **精准摘要提取**：能根据要求（如限制 120 字），智能生成文章摘要。
4. **创意封面生成**：能根据标题和摘要，利用 AI 绘画生成若干风格各异的候选封面图。

这些需求，除了素材需要做爬虫采集，其他可以通过集成现有的 `大模型 API` 来实现。目前市面上或许还没有完美的开源方案，但这无疑是未来的方向。

**工具的进化，本质上是为了让创作者能更专注于创造本身。** 从手动复制到一键发布，我们正在一步步把时间还给思考和创意。
